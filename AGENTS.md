# Manymade

This is an independent game project, not an Informa application or worktree.
The user-approved archive mission is the current implementation scope. Preserve
the full RPG direction in DESIGN.md; do not call the first mission the full game.

Use Phaser for presentation and a deterministic TypeScript rules module for all
state changes. Action previews must call the same resolver as committed actions.
Keep all assets local, all text escaped, and saves versioned and validated.
No backend, API credentials, paid services, or public deployment are needed for
the local mission. Public publishing requires owner authorization.

Run npm test and npm run build, then exercise real browser journeys and save
recovery. Simulation establishes mechanics, not human enjoyment or acceptance.
